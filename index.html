Clip-Watcher

Clip-Watcher is a personal desktop tool for Windows. It records Twitch live streams, detects highlight moments from chat activity and cuts short vertical clips with subtitles.

Finished clips can be sent as drafts to the user's own TikTok inbox via the official TikTok Content Posting API. Nothing is published automatically: the user reviews, edits and posts every draft in the TikTok app.
